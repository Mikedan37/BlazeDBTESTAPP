# Screenshots (optional)

This folder is for **exported screenshots or short screen recordings** used in docs, release notes, or talks—not source code.

Suggested captures (after **Debug → Clear all + seed (screenshot demo)**):

1. Dashboard — summary cards + “What this app is”
2. Check List — mixed checked / unchecked rows
3. Bug Tracker — open + resolved sections
4. To-Do List — open + completed sections
5. Notes — pinned / body preview
6. Settings — form with toggles
7. Debug — inspector + buttons
8. Activity Log — timeline

Naming: `tab-<name>-macos.png` or your team’s convention. Keep files out of git if they’re large, or commit small PNGs if you want them versioned.
